Изображение до/после-ссылка

Скролл изображения до/после.
Этот проект представляет собой интерактивный слайдер для сравнения двух изображений в формате «до/после», который позволяет пользователю с помощью ползунка плавно изменять видимую область второго изображения, наложенного поверх первого. В ходе работы над проектом тренируются навыки вёрстки адаптивных интерфейсов на HTML и CSS (flexbox, позиционирование, работа с overflow, стилизация ползунка), а также базовые приёмы JavaScript: поиск элементов в DOM (querySelector, querySelectorAll), навигация по дереву (closest), организация независимой логики для нескольких компонентов через цикл forEach, обработка событий (input, load, resize), динамическое изменение стилей элементов и защита от ошибок с помощью условных проверок. Это отличная практика для понимания взаимодействия HTML, CSS и JS при создании интерактивных элементов, развития навыков отладки, рефакторинга и добавления новых функций (анимация, подписи, адаптивность, сохранение состояния).
